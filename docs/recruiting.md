# 使ってくれる人の集め方

最終更新: 2026-10-02

> 社内の承認を待たずに、外で先に集めるための手順書。
> **会社名・部署・業務の話は、どこにも出さない。** 個人が作った物として出す。

---

## 0. 先に決めておくこと

| | 決めごと | 理由 |
|---|---|---|
| 人数 | **まず5〜10人で止める** | 全員の会話を毎日読める上限。直す場所は5人で十分見つかる |
| 費用 | 1通あたり ¥4.32。10人×1日1通×30日 = **約¥1,300/月** | 残高¥10,000なら安全圏。ここが崩れるのは人数が増えた時だけ |
| 報酬 | **無料。お金は払わない** | 報酬で来た人は、報酬のぶんだけ開く。知りたいのは「言われなくても5日目に開くか」 |
| URL | **公開の投稿には貼らない。リプ・DMで渡す** | 貼ると人数を制御できない。伸びた時にいちばん困るのは費用ではなく、全員の体験が落ちること |

**いまは10月。** 11月〜2月は日本のマラソンシーズンで、**この時期のランナーは目標が一番はっきりしている。**
「3月の大会に向けて」と言える人が最も多い時期なので、募集の時期としては今がいちばん良い。

## 1. どこで募るか（効く順）

### S. 走っている知り合い、1人から辿る

**いちばん速くて、いちばん当たる。** 走る人を1人知っていれば、その人の練習会には10人いる。

- 「作ったから、ちょっと試して文句を言ってほしい」と直接頼む
- その人に**他の人を紹介してもらう**。募集文より、走る仲間の一言のほうが強い
- 5人ならこれだけで埋まることがある

### A-1. X（旧Twitter）

ランナー界隈がいちばん厚い。**宣伝ではなく、作った経緯を書く。**

- 付けるタグ: `#ランニング` `#サブ3` `#サブ4` `#マラソン練習` `#ランナーさんと繋がりたい`
- 伸ばすなら**スクリーンショットを必ず付ける**（文字だけの投稿は流れる）
- **URLは貼らない。**「使ってみたい方はリプかDMください」で止める
- 効くのは「作りました」より「**毎日使っています**」

### A-2. LINEオープンチャット

「ランニング」「マラソン」「サブ4」で検索すると、数百人規模の部屋がいくつもある。

- **いきなり宣伝を投げない。** 2〜3日ふつうに会話に混ざってから
- 管理者に先に一言入れる（宣伝禁止の部屋が多い。断られたら引く）
- 当たると濃い。全員がランナーで、全員が目標を持っている

### A-3. 大会会場・ランステーションでの手配り

10月〜2月なら毎週どこかで大会がある。**QRコードを刷った名刺サイズの紙**を作る。

- 置かせてもらう場所: ランニングステーション（皇居周辺など）、ランニング用品店、ジムの掲示板
- 必ず**許可を取ってから**置く
- 紙は1枚に1つだけ: 「同じ距離を、2か月前の自分と比べます」+ QR + 「無料・テスト中」

### B. note / Zenn の開発記

**遠くまで届く。** 1回書けば、検索から何か月も人が来る。

- note なら「Geminiをコーチ代わりにしていたら、物足りなくなったので作った」という開発記
- Zenn / Qiita なら技術記事（**走る人にはエンジニアが多い**）。
  ラップ解析・過去との比較・急性慢性比のあたりは、技術的にも読み物になる
- 記事の最後に募集を1行だけ。本文で売らない

### C. Strava クラブ / Instagram

- Strava のクラブは、投稿が流れにくく残る。日本のクラブに参加して、活動の投稿に添える
- Instagram は `#朝ラン` `#ランスタグラム` `#マラソン練習`。
  **画面のスクショより、走った後の写真＋一言のほうが伸びる**

### D. クラウドワークス

**「1ヶ月使ってもらう」形では使わない。** 使うなら、こう変える。

- 2週間ふつうに使ってもらったあとの、**30分のインタビューに3,000〜5,000円**
- こうすると、ちゃんと使っていないと話せることが無いので、報酬が本物の利用を押す側に回る
- 人数は3人でいい

### やらないほうがいいこと

- YouTube のコメント欄、5ch、他人のリプ欄への書き込み → スパム扱いで、信用を先に失う
- 「モニター募集」という言葉 → 身構えられる。「作ったので、使ってくれる人を探しています」

## 2. 出す文章

### 原則

1. **1行目で、誰向けかを名指しする。**「大会に出る人向けです」
2. **機能を並べない。1つだけ見せる。** 全部書くと、何も伝わらない
3. **痛みのルールは必ず書く。** これが信用の核になる
4. **言い切らない。**「タイムが必ず縮まります」は書かない（景品表示法的にも危ない）
5. **無料・人数限定であることを書く。** 急かすためではなく、本当にそうだから

---

### X 用（案1・経緯から入る / 本命）

```
Geminiに練習メニューを相談するのが癖になってたんですが、
毎回「前はどうでしたか」と聞かれるのが面倒で。
こっちが覚えてるわけないだろ、と思って自分で作りました。

同じくらいの距離を、1〜4か月前の自分と比べて
「同じ心拍で12秒/km速くなってます」まで出します。

無料でテスト中。使ってみたい方はリプかDMください。
#ランニング #サブ4
```
*画像: 比較パネルのスクショ*

### X 用（案2・痛みのルールから入る）

```
ランニングのコーチアプリを作っています。

ひとつだけ絶対に曲げないルールがあって、
「痛みがある日は、何を聞かれても走らせない」。
8人いるコーチの誰を選んでも、ここだけは同じです。

走れる体を残すほうが、1回の練習より大事なので。

無料でテスト中です。興味ある方いたらDMください。
#ランニング #マラソン練習
```
*画像: コーチ8人の選択画面*

### X 用（案3・数字で殴る / エンジニア層に効く）

```
ラップの並びから、平均では見えないものを出しています。

・心拍ドリフト（後半どれだけ心拍が上振れたか）
・前半/後半のペース差
・直近7日 ÷ 直前4週 の比（1.5倍超えで故障が増えるやつ）

全部コードで計算してからAIに渡してます。
数えさせると桁を間違えて断定するので。

#ランニング #個人開発
```
*画像: ラップ解析の画面 + 積みすぎ警告*

### LINEオープンチャット用（短く、売らない）

```
はじめまして。走るときのコーチになるアプリを個人で作っていて、
使ってくれる人を5人ほど探しています。無料です。

・大会に出る or 出たい方
・時計かアプリ（Garmin / Apple Watch / NRC など）で記録している方

痛みがある日は絶対に走らせない作りにしてあります。
興味ある方いたら、個別にリンクをお送りします。
（宣伝になってしまっていたらすみません、消します）
```

### 貼り紙・配る紙（名刺サイズ）

```
┌─────────────────────┐
│  同じ距離を、            │
│  2か月前の自分と比べます。  │
│                         │
│  RUNCOACH               │
│  走る人のための、専属コーチ  │
│                         │
│  [ QRコード ]            │
│                         │
│  無料・テスト中           │
└─────────────────────┘
```

裏に3行だけ:
- 記録を送ると、区間ごとに読んで言葉を返します
- 痛みがある日は、絶対に走らせません
- 個人で作っています。感想をもらえると助かります

---

### note / 開発記の構成

1. **Geminiをコーチ代わりにしていた話**（共感される入口）
2. **足りなかったこと**: 過去の練習を覚えていない / 数字を数え間違える / 痛い日でも練習メニューを出す
3. **だから作った**: 計算はコードで、言葉はAIで
4. 画面を4枚
5. 最後に1行だけ募集

## 3. 画像（いちばん効くのはここ）

**文字だけの投稿は流れる。** 画像を4枚用意して、投稿ごとに使い分ける。

| # | 画面 | 言いたいこと |
|---|---|---|
| 1 | **過去の自分との比較**（練習の中身の上部） | 他に無いもの。これが主力 |
| 2 | コーチ8人の選択画面 | 選ぶのが楽しい。目を引く |
| 3 | 積みすぎの警告（ふりかえりの先頭） | 「怪我をさせない側」が伝わる |
| 4 | ラップの一覧（棒が並ぶ画面） | 本気で走る人にだけ刺さる。刺さり方は深い |

### 作るときの注意

- **中の名前・体重・体脂肪率はダミーにする。** 自分の数字をそのまま出さない
- スマホの画面は縦長なので、X では **2枚を横に並べて16:9** に組むか、**1枚を4:5** で出す
- 文字を乗せるなら**1枚に1行だけ**。スクショの中身が読めなくなる

## 4. 来た人に聞くこと（3つだけ）

多く聞くと、そこで半分が消える。

1. 月に何回くらい走りますか
2. 出る予定の大会、または出たい大会はありますか
3. 時計かアプリで記録していますか（Garmin / Apple Watch / Nike Run Club / Strava / なし）

**全部「なし」でも断らない。** ただし、枠が埋まってきたら1と2がある人を優先する。

### 断り方

> ありがとうございます。いまテストの枠が埋まっていて、
> 次に空いたらこちらからご連絡させてください。

## 5. 渡すときに必ず添える3行

```
・個人で作っているものです（会社とは関係ありません）
・医療行為ではありません。痛みが続く時は病院へ
・記録は本人のものです。消したい時は、いつでも全部消せます
```

利用規約・プライバシーポリシーは、アプリの中から読めるようになっている。
**先に読ませる必要はないが、聞かれたら即答できるようにしておく。**

## 6. 2週間の段取り

| 日 | やること |
|---|---|
| 1日目 | 画像4枚を作る。文面を1つ選ぶ |
| 2日目 | **走っている知り合いに直接頼む**（ここで3人埋まれば上出来） |
| 3日目 | X に投稿（案1）。反応を見る |
| 4〜5日目 | LINEオープンチャットを3つ探して、会話に混ざる |
| 6〜7日目 | note の開発記を書く |
| 2週目 | 週末の大会 or ランステへ紙を持っていく。X に案2・案3を投稿 |
| 随時 | **5〜10人に達したら、募集を止める** |

## 7. うまくいっているかの見方（`/admin`）

- **開いた → 選んだ → 1通目**: ここが半分を切るなら、入口の文章が悪い
- **5日目に開いているか**: 本当に見たいのはここ。報酬を払わない理由もここにある
- **👎の理由**: いちばんの改善材料
- **1回あたりの費用**: ¥6を超えたら見直す

---

## 8. 承認が降りたあと

社内には「作ってみました」の技術共有として出す。**募集はしない。**
外で集めた人の使い方と数字が、そのまま一番いい説明材料になる。
