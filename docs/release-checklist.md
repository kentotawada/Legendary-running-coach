## 1. いますぐ（Vercel の環境変数 → Redeploy）

上から順に。**環境変数はコードの既定より優先される。変えたら必ず Redeploy。**

| # | 変数名 | 入れる値 | なぜ要るか |

この2つで、いま壊れているものは直る。

## 3. ベータ中に見る数字（`/admin`）

| 見るもの | 何が分かるか |
|---|---|
| 1回あたりの費用 | 値付けの根拠 |
| 1通あたりの呼び出し回数 | 下げ余地（1に近いほど安い） |
| **使い回し（%）** | 指示文の並べ替えが効いたか。**0% なら効いていない** |
| **上限に当たった（会員）** | **お金を払ってでも使いたい人の数** |
| 「良くない」の理由 | いちばんの改善材料 |
| 不具合 | 黙って壊れていないか |
| 回数 ÷ 話した人 | 無料枠を何回にするかの根拠 |

## 4. 課金を始める時

### あなたがやること

**Stripe ダッシュボード**

1. 商品 → 「RUNCOACH プレミアム」／継続／**¥1,480 月**／JPY → **価格ID**（`price_`）
2. 開発者 → Webhook → `https://legendary-running-coach.vercel.app/api/billing/webhook`
   - イベント：`checkout.session.completed` / `customer.subscription.created` / `.updated` / `.deleted`
   - → **署名シークレット**（`whsec_`）
3. 開発者 → APIキー → **シークレットキー**（`sk_`）

**Vercel の環境変数**

| 変数名 | 値 |
|---|---|
| `STRIPE_SECRET_KEY` | `sk_...` |
| `STRIPE_PRICE_ID` | `price_...` |
| `STRIPE_WEBHOOK_SECRET` | `whsec_...` |
| `LEGAL_ADDRESS` | 住所 |
| `LEGAL_PRICE_TEXT` | `月額 1,480円（税込）` |
| `LEGAL_MANAGER_NAME` | 責任者名（省略可） |

> **住所の記載は法律上必須。** 自宅を出したくなければバーチャルオフィス（月1,000円〜）。
> **4つが埋まるまで、申し込みは受け付けない**作りにしてある（`/commerce` が未完成なら 503）。

> テストモード（`sk_test_`）で一度通してから本番キーに替えること。
