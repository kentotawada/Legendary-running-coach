## Strava の設定手順

### 1. アプリを登録する

**[strava.com/settings/api](https://www.strava.com/settings/api)** を開く（Strava アカウントでログイン）。

| 欄 | 入れるもの |
|---|---|
| Application Name | `RUNCOACH` |
| Category | `Training` |
| Club | 空欄 |
| Website | `https://legendary-running-coach.vercel.app` |
| Application Description | ランナー向けのAIコーチ。練習記録を取り込んで助言します。 |
| **Authorization Callback Domain** | `legendary-running-coach.vercel.app` |

> ⚠️ **Callback Domain は「ドメインだけ」。** `https://` もパスも入れない。
> ここを間違えると、連携しようとした時に Strava 側でエラーになる。

ロゴの画像を求められたら、適当な正方形の画像で構わない（あとで差し替えられる）。

### 2. 発行された値を Vercel に入れる

Settings → Environment Variables

| 変数名 | どこの値か |
|---|---|
| `STRAVA_CLIENT_ID` | Strava の **Client ID**（数字） |
| `STRAVA_CLIENT_SECRET` | Strava の **Client Secret**（秘密の値。**どこにも貼らない**） |
| `NEXT_PUBLIC_SITE_URL` | `https://legendary-running-coach.vercel.app` |

→ **Redeploy**

`NEXT_PUBLIC_SITE_URL` を入れるのは、**戻り先を固定するため**。
これが無いとリクエスト元から組み立てるので、プレビュー環境だと
Strava に登録したドメインと食い違って弾かれる。

### 3. 確認

1. `/api/health` が `"stravaAvailable": true`
2. アプリの「つなぐ」から Strava を選ぶ
3. Strava の認可画面が出て、許可すると戻ってくる
4. 練習記録が取り込まれる

アプリが求める権限は `activity:read_all`（練習記録の読み取りのみ）。
書き込みは求めない。

### 注意

- **人数の上限**：Strava は新しいアプリに利用人数や回数の制限をかけることがある。
  ベータで人が増えて弾かれるようなら、Strava に増枠を申請する
- **審査**：登録自体に審査は無く、すぐ使える
