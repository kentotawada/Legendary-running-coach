## 1. Vercel の環境変数（10分）

**Vercel → プロジェクト → Settings → Environment Variables**

| 変数名 | 入れる値 |
|---|---|
| `GEMINI_PRICE_PER_MTOK` | `0.5,3` |
| `NEXT_PUBLIC_SITE_URL` | `https://legendary-running-coach.vercel.app` |
| `DAILY_TURN_BUDGET` | `300` |

**入れ終わったら必ず Redeploy。** Deployments → 最新のものの「…」→ Redeploy。
**環境変数は入れただけでは効きません。**

<details>
<summary>それぞれ何のための数字か</summary>

- **`GEMINI_PRICE_PER_MTOK`** … `/admin` の金額を出すための単価。
  `2,12` のままだと**実際の4倍**の金額が出ます。値付けを間違えます。
- **`NEXT_PUBLIC_SITE_URL`** … 楽天と Strava の両方が使います。
  **無いと商品が1件も出ず、Strava の自動登録も動きません。**
- **`DAILY_TURN_BUDGET`** … アプリ全体で1日に話せる回数の上限。お金の蛇口。
  300回 × 約¥4.3 = **1日あたり最大 ¥1,300**。10人なら 300 で十分です。

</details>

## 2. Strava の登録（30分）★今回から必須

**これが「スクショを送らなくていい」の正体です。** ここが空だと、
走った記録は自動で入らず、通知も出ず、ただのチャットになります。

### やること

1. **https://www.strava.com/settings/api** を開く（Strava にログインした状態で）
2. アプリケーションを作る。入れるのは3つだけ：

   | 欄 | 入れる値 |
   |---|---|
   | Application Name | `RUNCOACH`（何でもよい） |
   | Website | `https://legendary-running-coach.vercel.app` |
   | **Authorization Callback Domain** | `legendary-running-coach.vercel.app` |

   > **Callback Domain は「ドメインだけ」。** `https://` も `/` も付けません。
   > ここを間違えると、連携ボタンを押した人が全員エラーになります。

3. 作ると **Client ID** と **Client Secret** が出ます
4. Vercel の環境変数に入れる：

   | 変数名 | 入れる値 |
   |---|---|
   | `STRAVA_CLIENT_ID` | 画面の Client ID（数字） |
   | `STRAVA_CLIENT_SECRET` | 画面の Client Secret |

5. **Redeploy**

### 走った記録を受け取る設定（webhook）は、何もしなくていい

**自動で登録されます。** 誰かが最初に Strava をつないだ時に、アプリが自分で登録します。

確かめたい時だけ、これを叩いてください（`CRON_SECRET` は 3. で作るもの）：

```
curl -H "Authorization: Bearer <CRON_SECRET>" \
  https://legendary-running-coach.vercel.app/api/strava/subscription
```

- `"matches": true` … 届く状態。**これだけ見れば十分です**
- `"matches": false` で別のURLが出ている … 同じURLに `-X POST` を足して叩くと直ります

> ⚠️ **Client Secret をチャットに貼らないでください。** 入れる場所は Vercel だけです。

## 3. 通知の鍵（15分）★今回から必須

**ホーム画面に追加してもらう案内を出した以上、通知が動いていないと嘘になります。**

### 3-1. VAPID の鍵を作る（2分）

パソコンのターミナルで1回だけ：

```
npx web-push generate-vapid-keys
```

Public Key と Private Key が出ます。

### 3-2. Vercel に入れる

| 変数名 | 入れる値 |
|---|---|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | 出てきた Public Key |
| `VAPID_PRIVATE_KEY` | 出てきた Private Key |
| `CRON_SECRET` | 自分で決めた長い文字列（32文字以上。パスワード生成でよい） |

**Redeploy。**

> ⚠️ **`VAPID_PRIVATE_KEY` と `CRON_SECRET` は GitHub に入れないでください。**
> 入れる場所は Vercel だけです。チャットにも貼らないでください。

## 4. `/api/health` を開く（1分）

スマホのブラウザで
`https://legendary-running-coach.vercel.app/api/health`

**見るのは3か所。**

```
"readyToShare": true                     ← true なら配れる状態
"priceUsdPerMTok": {"in":0.5,"out":3}    ← 0.5 と 3 になっているか
"pending" の中に「練習の自動取り込み（Strava）」と「通知」が無い
```

- `readyToShare` が **false** → `"blocking"` に理由が出ます。そのまま貼ってください
- `priceUsdPerMTok` が **`{"in":2,"out":12}`** → 1. に戻って `0.5,3` に直す
- `pending` に **Strava** や **通知** が残っている → 2. か 3. の入れ忘れか、Redeploy 忘れ

> **`pending` は空になりません。** Stripe と特商法は、課金を始めるまで不要です。
> **`pending` ではなく `readyToShare` を見てください。**

## 6. 自分以外の端末で、最初から通しで触る（20分）

**ここがいちばん大事です。上の設定より大事です。**

家族の端末でも、ブラウザのシークレットウィンドウでも構いません。
**自分の記録が入っていない状態**で開くのがポイントです。

- [ ] 開く → 見出しと「かんたん」の段が見える
- [ ] 同意 → コーチを1人選ぶ → 始める
- [ ] コーチから最初の一言が返ってくる
- [ ] **帯に「今日やること」が出ている**
- [ ] 帯を押す → 理由・手順・「できない日のために」が出る
- [ ] **「この先7日」が並んでいる** → 日を押す → 「別の日に移す」が動く
- [ ] 「今日5km走りました」と打って、返事が来る
- [ ] 時計のスクリーンショットを送る → 記録として入る
- [ ] **Strava をつなぐ** → 過去の練習がまとめて入る
- [ ] カルテ →「最近の練習」から1本開く → **「過去の自分と比べて」が出る**
- [ ] **「画像で共有」を押す** → 画像が出てくる → 名前が入っていないことを確認
- [ ] 「シューズのおすすめ教えて」→ 商品名と価格が並ぶ
- [ ] `/terms` `/privacy` `/disclaimer` を自分で読む

> **詰まった場所が、そのまま全員の詰まりになります。**
> 「分かりにくいけど自分は分かる」も、メモしてください。
> あなたは作った本人なので、**あなたが迷わないのは当たり前**です。
