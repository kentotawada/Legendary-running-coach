## 1. Vercel の環境変数（10分）

**Vercel → プロジェクト → Settings → Environment Variables**

3つ入れます（もう入っていれば飛ばす）。

| 変数名 | 入れる値 |
|---|---|
| `GEMINI_PRICE_PER_MTOK` | `0.5,3` |
| `NEXT_PUBLIC_SITE_URL` | `https://legendary-running-coach.vercel.app` |
| `DAILY_TURN_BUDGET` | `300` |

**入れ終わったら必ず Redeploy。** Deployments → 最新のものの「…」→ Redeploy。
**環境変数は入れただけでは効きません。** ここを忘れると、何も変わりません。

<details>
<summary>それぞれ何のための数字か</summary>

- **`GEMINI_PRICE_PER_MTOK`** … `/admin` の金額を出すための単価。
  いま `2,12`（上位モデルの値段）のままだと、**実際の4倍**の金額が出ます。
  値付けをこの数字で決めるので、ここがずれていると判断を間違えます。
- **`NEXT_PUBLIC_SITE_URL`** … 楽天と Strava の両方が使います。
  **無いと、商品のおすすめが1件も出ません。**
- **`DAILY_TURN_BUDGET`** … アプリ全体で1日に話せる回数の上限。お金の蛇口です。
  300 回 × 約 ¥4.3 = **1日あたり最大 ¥1,300**。
  30人に配るなら 300 くらいが目安。低すぎると、数人が使っただけで全員止まります。

</details>

## 3. 自分以外の端末で、最初から触る（20分）

**ここがいちばん大事です。** 上の設定より大事です。

家族の端末でも、ブラウザのシークレットウィンドウでも構いません。
**自分の記録が入っていない状態**で開くのがポイントです。

順番にやって、詰まったところをメモしてください。

- [ ] 開く → **見出しと「かんたん」の段が見える**
- [ ] 同意にチェック → コーチを1人選ぶ → 始める
- [ ] コーチから最初の一言が返ってくる
- [ ] 「今日5km走りました」と打って、返事が来る
- [ ] 時計のスクリーンショットを送る → 記録として入る
- [ ] **縦に長いスクショ**を送る → 何枚かに分かれる → **× で1枚ずつ消せる**
- [ ] 「シューズのおすすめ教えて」→ **商品名と価格が並ぶ**
  （「楽天市場で探す」だけなら、`/admin` の「不具合」に理由が出ます。貼ってください）
- [ ] カルテを開いて、送った記録が入っている
- [ ] `/terms` `/privacy` `/disclaimer` を自分で読む

> **詰まった場所が、そのまま30人ぶんの詰まりになります。**
> 「ちょっと分かりにくいけど自分は分かる」も、メモしてください。
> あなたは作った本人なので、**あなたが迷わないのは当たり前**です。

## 7. ベータが始まったら（毎日1分）

`/admin` を開いて、**3つだけ**見てください。

| 見るところ | こうなっていたら教えてください |
|---|---|
| **入口** 開いた → 選んだ → 1通目 | 「選んだ」が半分を切っている |
| **今日の全体の残り** | 棒が赤い（8割を超えた）／「全体の上限で止まっています」が出た |
| **不具合** | 1件でも出ている |

あとは **「良くない」の理由**。ここがいちばんの改善材料です。

> 数字を見て判断する必要はありません。**そのまま貼ってくれれば読みます。**
